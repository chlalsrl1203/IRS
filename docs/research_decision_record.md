## 방향 신호 보관 (행동으로 옮기지 않은 것)

**이 절은 "아직 결정이 아닌 관측"을 잃어버리지 않기 위한 것이다.** 여기 있는
항목을 근거로 코드를 바꾸면 안 된다.

### S-1. IRS 성장구조가 체계적으로 낙관적일 가능성 (2026-08-16)

서로 **독립적인 두 축**이 같은 방향을 가리킨다:

| 축 | 관측 | 강도 |
|---|---|---|
| 축소 부족 | 함의 w 중앙값 0.807(원시값의 19%만 축소), 10건 중 8건 과대추정 | 양측 p=0.109 — **유의하지 않음** |
| 성장지속기간 | n=12인데 CAP fade 가정에서 도출한 PV 등가기간은 3.14~8.46년 | 외부 수치 **UNVERIFIED**, 매핑 미검증 |

**둘 다 개별로는 근거가 약하지만 방향이 일치한다.** 이 일치가 우연인지는
H-006이 해소되면 부분적으로 답이 나온다. **그때까지 어느 파라미터도 바꾸지
않는다** — 약한 근거 두 개를 합쳐도 강한 근거가 되지 않는다.

### S-2. DSGX는 두 독립 축에서 동시에 취약한 유일한 종목 (2026-08-16)

- 모델선택 축: C등급 → 대안모델이면 A등급(매수 유니버스 진입) — 거짓탈락 후보
- 성장지속기간 축: n=15에서 판정이 '적정가/경계선'→'저평가 가능성'

두 축 모두 **더 저평가로 보이는 방향**이라 확증편향에 특히 주의해야 한다.
현재 공식 판정은 C(적정가/경계선)이며 **변경하지 않았다.**

### 정정 기록 (§35 — 덮어쓰지 않는다)

**정정 2건 (2026-08-16, 코드 실측으로 이전 서술 수정)**

1. **"음수 FCF 기준연도를 v3.19 가드가 자동으로 앞당긴다"는 서술은 틀렸다.**
   `_cagr`은 `start<=0`이면 **예외를 던져 차단만** 하며 자동 이동 로직은 없다
   (`base_5y = years[-6]` 고정). MNDY 2021·UBER 2022·BKNG 2019는 전부 분석자가
   `cagr_base_year_override`를 사유와 함께 **수동 입력**한 결과다(4/34).
   → 근사-0 기준연도는 가드의 부작용이 아니라 **주관적 입력**이다.

2. **"FCF CAGR 아티팩트 11/34"는 느슨한 기준의 결과였고, 활성 여부를 구분하지 않았다.**
   엄밀한 기준(기준연도 FCF < 최종연도의 10%)으로는 **5/34**(MNDY·DUOL·UBER·SE·VRT)이며,
   **그중 RG에 실제 채택된 것은 0건**이다 — `min()`이 전부 걸러낸다.
   → 이 문제는 **잠재적(latent)이며 현재 활성 결함이 아니다.** 단 FCF 파생 변수를
   새로 만들면 즉시 활성화되므로, 그것이 §17이 분리를 먼저 요구한 이유다.
   별개로 **필드명 `fcf_cagr_5y`인데 실제 span이 5가 아닌 종목이 4건**
   (BKNG 6·TCOM 6·MNDY 4·UBER 3) — 이건 오독 위험이 실재하는 활성 명명 결함이다.
