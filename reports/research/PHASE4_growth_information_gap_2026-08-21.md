## Finding — 재개조건은 충족됐다. 그런데 blocker가 **이동**했다.

### 후보 1: ROIC / ROIIC

캐시된 SEC companyfacts 실측: equity 34/34 · assets 34/34 · 유효세율 34/34 ·
cash 33/34 · goodwill 31/34 · 총부채 29/34.
**데이터 가용성은 해소됐다**(#31의 2/34 → 22~33/34).

그런데 실제 계산해보니 새 blocker가 드러났다:

| 투하자본 정의 | ROIC 계산 | ROIIC(3y) |
|---|---|---|
| 자기자본 + 이자부부채 − 현금 | 22/34 | 13/34 (그중 4종목은 분모 사용 불가 → **실질 9/34**) |
| 총자산 − 현금 | 33/34 | 23/34 |

**두 정의의 ROIC 비율: 중앙값 1.50 · 범위 0.60 ~ 206.72.**

극단은 자기자본이 근사-0/음수인 기업이다 — **MCK ROIC 1347.77%**(좁은 정의)
vs 6.52%(넓은 정의). COR도 38.87% vs 2.53%. 누적 자사주매입으로 자기자본이
거의 남지 않은 유통업에서 분모가 폭발한다.

**§13 CORE MODEL CHANGE GATE 불통과**: 조건 3(데이터 품질)·7(proxy dependency)·
8(false precision)에 정면으로 걸린다. 정의 선택이 결과를 지배하는 지표를
종목 간 비교에 쓸 수 없다 — 결정 #32가 proxy ROIIC를 REJECT한 이유
("업종간 비교 불가")가 **exact 정의에서도 재현**됐다.

부수 확인 — ROIC는 기존 지표와 **독립적이다**(정보량 자체는 있다):

### 후보 2: 희석 드래그 — ⚠️ 내가 틀린 결과를 배선했다가 되돌렸다

`WeightedAverageNumberOfDilutedSharesOutstanding`이 **34/34** 확보된다.
결정 #26이 공백으로 남긴 채널을 잴 수 있게 됐다.

    희석 드래그 = 주당 FCF CAGR − 총 FCF CAGR

**초판 결과(틀림)**: 매수 유니버스 7종목·비중 46.74%가 −5%p 초과,
TTD 총 +19.17% → 주당 **−24.92%**, TCOM 총 +13.04% → 주당 **−21.18%**.
"총 FCF는 성장했는데 주당은 감소했다"는 극적인 결론을 얻었고,
**그것을 자본배분 경로(매수리스트 진단축)에 배선까지 했다.**

**검증에서 전부 무너졌다.** 주식수 시계열을 연도별로 보니:

```
TTD  FY2021 ×10.2   ← 2021년 10:1 주식분할
TCOM FY2021 ×8.4    ← ADS 비율 변경
DUOL FY2021 ×1.8    ← IPO(2021-07)
MNDY FY2022 ×1.5    ← IPO(2021-06)
UBER FY2019 ×2.6    ← IPO(2019-05)
PDD  FY2025 ×1002   ← ADS/보통주 단위 혼재
BRO  FY2022 ×1004   ← 단위 혼재
```

**주식분할·IPO·ADS 비율변경은 희석이 아니다.** 가장 극적이던 네 종목
(TTD·TCOM·DUOL·MNDY)이 전부 오염이었다.

즉시 배선을 되돌리고(`git checkout` + 산출물 복원, 동일성 확인), 오염 검출을
**사전 정의된 도메인 제약**으로 넣었다 — 정상적인 연간 희석이 50%를 넘는 것은
사실상 불가능하므로 인접 연도 비율 1.5배 이상/0.67배 이하를 구조적 점프로 본다.
이 임계값은 결과를 보고 고른 것이 아니다(§19 준수).

**정정 후 결과:**

| | 초판(틀림) | 정정 후 |
|---|---|---|
| 계산 가능 | 25/34 | **19/34** |
| 매수 유니버스 측정 가능 | 12/12 | **6/12** |
| −5%p 초과 비중 | 46.74% | **12.16%** |

| 매수 유니버스 (측정 가능 6종목) | 비중 | 드래그 |
|---|---|---|
| SE | 7.39% | −10.34%p |
| UBER | 4.77% | −6.82%p |
| WDAY | 4.51% | −2.98%p |
| GEN | 18.00% | −0.73%p |
| PGR | 12.00% | −0.02%p |
| ACGL | 12.00% | **+2.06%p**(자사주매입) |

**측정 불가 6종목·비중 41.33%**(BRO·DUOL·MNDY·PDD·TCOM·TTD).

## Dependency — SBC와 중복인가 (§6)

희석 드래그 vs `sbc_to_fcf_pct` 순위상관 **−0.597**(n=25, 정정 전 표본).
부분 중복이나 두 지표는 **다른 것을 잰다**:

- `sbc_to_fcf_pct` — 보상비용의 **크기**
- 희석 드래그 — 주주 지분의 **순변화**(신주발행 − 자사주매입)

양방향 반례: **VRT** SBC 2.4%인데 드래그 −7.66%p / **WDAY** SBC 58.6%인데
−2.98%p / **GWRE** SBC 57.6%인데 −0.91%p. BRO 정성조사(2026-08-04)가 이미
지적한 *"M&A 주식대가 다일루션(~19%, SBC와 무관 — 표준 SBC 교차검증이 놓치는
채널)"* 이 바로 이것이다.

⚠️ 이 상관은 **오염 정정 전 표본**으로 계산됐다. 정정 후 n=19에서는 재계산하지
않았다 — 결론(부분 중복·독립 성분 존재)이 바뀔 만한 근거가 없고, 반례 3건은
전부 오염되지 않은 종목이다.
