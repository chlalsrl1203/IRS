# IRS 발행 전 교차검증(fresh-eyes)

**왜 별도 스킬인가**: 코드를 방금 짠 세션은 자기 가정을 스스로 의심하기
어렵다. 이 프로젝트가 이미 겪은 사고 전부가 "짜는 순간엔 맞다고 믿었던
것"이었다(TYL SBC 62%→실제 24.4%, RAR 100배, MU FCF CAGR "82% 아티팩트"를
검증 없이 단정했다가 재확인). 이 체크리스트는 **작성자 관점을 벗어나
독자/감사자 관점으로 다시 본다**는 뜻에서 "fresh eyes"다 - 별도 모델이나
외부 LLM 호출은 필요 없다(이 프로젝트는 engine/에 신규 의존성을 추가하지
않는다는 원칙을 P0-03에서 이미 확정했다).

## 체크리스트 - ledger 저장 전 / engine/ PR 전

**① 출처 계층 확인 - 2차 출처를 1차인 것처럼 인용하지 않았는가**
- 웹서치 요약을 검증 없이 SEC 원자료인 양 썼는가? TYL이 정확히 이
  실수였다(경량검증 에이전트가 2차 출처 FCF 수치를 잘못 인용, 실제
  1e-12 정밀도로 대조 가능한 SEC 값과 3배 차이).
- 숫자를 손으로 옮겨 적은 곳이 있는가? 반올림된 화면 출력을 그대로
  베끼면 정밀도가 깨진다(SE 2026-09-04: `4375700000.0`을 옮겨 적었다가
  정확값 `4375664000.0`과 1.9e-6 어긋나 골든테스트가 잡음).

**② 단위 - 이 프로젝트가 반복 밟은 함정 5종을 직접 대조**
- RAR: 첫 인자가 퍼센트 숫자(-22.39)인가 소수(0.1234)인가 -
  `rar_from_decimal_return`을 썼는가?
- `market_cap`: `implied_growth_*`는 원화 그대로, `structural_discount_
  rate`/`classify_lynch_type`은 10억 단위 - 섞이지 않았는가?
- 통화: `currency` 필드가 재무제표 통화를 말하는지 거래 통화를 말하는지
  (TCOM 사례 - 두 의미가 충돌한 채 방치돼 있음, 재사용 시 반드시 확인).
- 실질 vs 명목: 인플레이션 환산 없이 비교하지 않았는가(VOO EPS 실질/명목
  함정, v3.35).
- SBC 비율 필드명이 `_pct`인데 실제로는 0~1 소수를 담는가(`sbc_to_fcf_pct`
  - 이름과 실제 스케일이 다르다는 걸 알고 쓰고 있는가).

**③ CAGR 기준연도 - 시작점이 저점/고점/근사-0인지 확인**
- 기준연도가 코로나 저점(BKNG형)·M&A 단계상승 직후(GEN/ROP형)·거의
  0에 가까운 값(MU형, PODD형, ONON형)이 아닌지 raw 시계열을 **눈으로**
  본다. 표면 CAGR이 "안 튀어 보인다"는 사실 자체가 안전 근거가 못 된다
  (GEN 사례 - 양끝이 서로 다른 M&A로 상쇄돼 CAGR이 정상범위처럼 보였음).

**④ 도구가 산출한 극단값을 그대로 믿지 않았는가**
- Gap이 코퍼스 관측범위(약 -14%p~+24%p)를 크게 벗어나면 그 자체가
  경고다 - 근거를 다시 확인한다.
- `sensitivity_check`/`sbc_cross_check`/`gap_range_over_assumptions` 중
  하나라도 flip을 보고하면, 그 flip이 "부분 적용의 산물"인지(TCOM
  PHASE 1 사례) "고유 신호"인지(TTD SURVIVES 사례) 구분하지 않은 채
  결론에 반영하지 않았는가.

**⑤ 결론이 사후합리화가 아닌가**
- `falsification_conditions`에 과거 분석에 소급 작성한 조건이 있는가
  (금지 - 결과를 이미 안 뒤 끼워맞추는 것과 미리 검증조건을 박아두는
  것은 다르다).
- "가설이 맞았다"로 결론 내리기 전에, 가설을 만든 표본으로 그 가설을
  다시 검정하지 않았는가(순환검증 - H-006이 동기가 된 10건을 검정
  표본에서 제외한 것과 같은 원칙).

## 발견하면 하는 일

이 스킬은 판정을 내리지 않는다 - 위 체크리스트 중 걸리는 항목이 있으면
**그 사실만 보고하고 원인을 재확인**한다(→ `irs-systematic-debugging`으로
넘긴다). 통과하면 조용히 넘어간다 - 매번 장문 보고를 만들지 않는다.
